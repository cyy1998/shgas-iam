# 组织搜索

内部应用可按组织属性和组织路径筛选组织。所有有效的内部应用都能查询完整公开字段，不按应用限制组织子树。
查询对象是组织，不支持按成员、岗位、角色或责任人反查，也不查询历史组织。

## 查询与结果

搜索包含未删除的启用、暂停和禁用组织，需要限定状态时自行筛选。
默认返回组织编码和名称，也可选择类型、状态、层级、虚拟或实体属性，以及从根到自身的路径字段。

- 路径保留全部祖先，包括已暂停或禁用的祖先。
- 层级从根的第 1 层起算；相对距离从目标自身的 0 起算，父级为 1。
- 可以组合组织属性、路径节点和子树条件，子树条件包含所选组织自身。
- 可省略条件浏览目录；筛选和返回字段使用同一份已发布文档。选择路径字段保留全部节点和次序，选择父字段返回其完整公开子树。
- 可按公开根字段排序；相同排序值按内部唯一标识保持确定次序，不改变路径节点顺序。
- 默认一次返回全部匹配组织，最多 500 个；开启分页后每页最多 500 个，总匹配数量可以超过 500。
- 分页返回本页列表、同一次数据库快照中的精确总数和实际页码、每页条数。无匹配或超过末页时列表为空，仍保留真实总数。

Internal 精确组织详情返回完整已发布 Organization Document，与选择全部根字段的搜索单项一致，包含暂停或禁用但未删除的组织。
管理端详情、管理搜索、组织树和选择器继续使用各自的管理模型。

## 更新延迟

各组织分别在后台更新，单份结果内部一致，但一次查询可能读到不同组织的新旧资料。
不同翻页请求各自读取当时的已发布资料，期间的更新可能造成重复或漏看；分页不提供固定快照导出。
新建组织首次发布前可能搜不到；刚删除的组织也可能暂时仍出现在结果中。
祖先编码、名称或类型变化后，其全部后代的路径资料也需要更新。

构建失败时保留已有合法旧资料并重试，没有固定的更新时间保证。

## 查询失败时

条件或分页参数非法、过于复杂，或关闭分页时匹配超过 500 个组织，整次查询被拒绝，不截断返回。
查询超时或本次返回范围中的完整文档损坏时也会失败，即使损坏字段没有被选择。
分页只完整校验本页文档；总数统计所有可见匹配项，不表示其他页文档已通过完整性核验。

尚未发布、缺失或版本不匹配的文档会被跳过，其他匹配组织仍可返回。因此成功响应不代表源组织已全部进入搜索。
更新异常时应修复搜索文档，不要重复修改源组织来触发补偿。

精确详情没有当前可读条目时返回 404，可能表示不存在、已删除、尚未发布或 schema 不匹配；它不保证源对象不存在。
文档损坏、查询失败或超时返回 503，不从源表重新拼装详情。

条件和示例见[搜索接入](../../guides/search.md)，重建见[数据维护](../../releases/data-maintenance.md)。
