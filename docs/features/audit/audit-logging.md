# 审计日志

审计日志记录安全敏感操作，供有权限的管理员追责和查询。内容包括操作者、目标、操作类型、结果、请求来源和必要的脱敏说明。
运行日志用于排障，不能替代业务审计。

## 查询与记录范围

可以按一种或多种操作类型筛选，并单独筛选成功、失败结果。已知操作显示标准名称，未知类型保留原名称。
HR 的组织责任管理权限不包含全局审计或责任操作日志权限。

会话终止、解除登录限制、凭据轮换和凭据读取等安全操作会记录审计。合法的重复操作可能没有业务变化，仍会留下操作意图。
会话操作分别记录确认终止、失败和结果未知的数量；未知结果不能计为成功。

## 敏感信息

日志使用业务身份、脱敏手机号和变化摘要定位操作，不保存密码、验证码、登录凭据、Cookie、Secret 或可直接认证的摘要。
会话内部状态、原始异常及其他敏感上下文也不会直接展示给管理员。

## 审计失败时

部分操作先改变登录状态，再保存审计。审计失败不撤销已经完成的会话终止或限制解除。
界面提示“可能已生效”时，先刷新确认当前状态，再处理审计修复；不要为了补日志重复执行原操作。

凭据读取有额外限制：审计提交未确认时不交付原文。本人改密后的审计或下线失败，也不会恢复旧密码。

历史数据迁移见[运维入口](../../releases/README.md#一次性迁移与旧版本)。
