# 应用单点登录

接入应用可以使用 IAM 验证用户身份。用户已有有效 IAM 登录时，通常无需再次输入凭据；登录完成后返回发起请求的应用。

## 选择接入方式

每个应用选择一种协议，由管理员配置允许的回调地址和用户信息范围，再启用登录。

| 方式                | 适用情况                           | 应用负责什么                                   |
| ------------------- | ---------------------------------- | ---------------------------------------------- |
| Custom SSO 业务回调 | 业务后端接收登录结果并管理本地会话 | 接收回调、兑换登录结果、保存本地会话和处理退出 |
| Custom SSO 托管回调 | 由 IAM 在业务域写入登录 Cookie     | 部署回调代理，接入用户信息或网关鉴权           |
| OIDC                | 使用标准 OIDC 客户端接入           | 按登记的入口和回调完成授权、验证身份与退出     |

OA、微信可信登录可先完成 IAM 身份验证，再继续目标应用的登录。发起身份验证的系统和目标应用可以不同。

## 登录流程与限制

1. 用户从应用发起登录，IAM 校验应用和返回地址。
2. 已有有效登录时继续授权；否则完成身份验证，再继续原请求。
3. 应用接收一次性登录结果，按所选方式建立访问状态，并取得获准提供的用户信息。

内外网入口可能对应不同 OIDC 身份，接入应用须固定入口，不能混用。
当前不支持在已有有效 IAM 登录下再次弹出认证流程；要求重新认证的 OIDC 请求会被拒绝。
登录结果只能兑换一次。兑换失败或结果不确定时，返回应用重新发起，不能重复兑换；部分失败还可能使原应用会话失效。

## 信息与退出责任

应用只收到管理员配置范围内的用户信息，数据可能有更新延迟，详见[用户信息共享](subject-delivery.md)。
IAM 提供身份和角色信息，具体业务权限仍由应用判断。

IAM 退出会终止相应登录的后续在线访问。应用自己建立的本地会话、已复制资料和离线身份凭证，由应用自行处理。

实际接入步骤见[Custom SSO 指南](../../guides/custom-sso.md)和[OIDC 指南](../../guides/oidc.md)；配置管理见[应用接入配置](../admin/client-sso-configuration.md)。
