# 登录与会话

用户通过统一登录访问 IAM 和接入应用，也可以找回密码、修改密码或退出会话。管理员可在授权范围内查看和终止会话、解除临时登录限制。

## 登录与找回密码

- 支持密码、短信验证码，以及已接入的 OA、微信登录。各方式有各自的身份校验条件。
- 登录应从目标应用发起。已有有效登录时，通常直接回到原应用；请求失效时需返回应用重新发起。
- 登录检查暂时失败时，页面提示重试，不会直接显示密码表单。找回密码页面可单独使用。
- 找回密码使用已绑定手机号。账号不存在或未绑定手机号时，统一提示无法获取号码，并停止发码和重置。
- 页面只展示脱敏手机号，但号码片段仍可能透露账号信息。

短信验证码按手机号共用 60 秒冷却，登录、找回密码和绑定手机号共用额度，换设备或浏览器也不会重置。
发送失败或超时仍需等待冷却结束；使用验证码不会提前解除冷却。普通业务短信不受此限制。

密码登录使用加密凭证。当前默认配置仍有防重放时间窗口缺口，需注意[已知限制](../../releases/authentication-and-session.md#凭证时间窗口与防重放限制)。

## 登录与应用会话

一次 IAM 登录可关联多个应用。登录期限固定，普通访问不会延长；应用会话的期限不能超过所属 IAM 登录。
退出某个应用会话不影响其他应用或其他 IAM 登录；终止 IAM 登录后，其关联应用的后续在线访问都会被拒绝。

账号禁用或删除后，新的访问会被拒绝。已经通过检查的操作仍可能完成。重新启用账号不会恢复旧会话，需要重新登录。
应用状态和接入配置也会影响访问，规则见[应用接入配置](../admin/client-sso-configuration.md)。

## 查看和终止会话

管理员在会话管理页面按用户查找登录记录，也可展开查看各应用会话和临时登录限制。本人安全操作仅限本人。
页面支持手动刷新，不自动轮询；会话记录存在不代表账号当前仍能访问。

- 可以终止单个应用会话、单次 IAM 登录或选定用户的一批会话。
- 管理操作保护当前登录；批量下线仍会处理当前登录关联的应用会话。
- 批量操作只处理开始时选定的记录，新建立的会话可能不在本批范围内。
- 记录列表可能不完整，显示总数不能当作实时在线人数。查询异常时先重试，不按不完整页面扩大撤销范围。

失败或结果未知的项目会单独列出。用户确认后可重试原批次；若响应丢失且没有批次记录，先重新查询，再发起新操作。
部分失败不会恢复已经终止的会话，界面也不会自动重试。

## 修改密码与全部下线

本人改密或全部下线保留当前 IAM 登录，但会终止其关联应用会话及本次选中的其他会话。
改密先保存新密码，再处理会话下线。若下线失败，密码仍已修改，应处理未完成项目，不要重复改密。
账号禁用、删除或离职后的遗留清理只处理原有登录，不应影响后来重新启用账号建立的新登录。

## 临时登录限制与异常处理

登录失败过多会暂时阻止新的认证，已有会话不受影响。页面显示自动解除时间，管理员也可按权限提前解除。
解除会同时清除当前失败历史；之后再次失败会重新计数，没有额外宽限期。

会话或限制操作可能已经生效，但审计保存失败。此时刷新确认当前状态，并保留修复提示；刷新成功不等于审计已补齐。
IAM 不保证第三方自行保存的本地会话同时退出，接入应用须处理自己的退出和数据清理。

运维恢复见[登录与会话手册](../../releases/authentication-and-session.md)。
