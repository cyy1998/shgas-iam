# 用户、组织与任职

用户档案、组织和岗位是管理端维护的源事实。任职把用户与特定组织和岗位关联。
有效任职是角色解析和对外人员资料的基础。

## 账号与任职生命周期

- 开放任职包含启用和暂停，均须引用启用且未删除的组织与岗位。同一用户在同一组织和岗位下最多有一条开放任职。
  暂停可恢复，结束保留历史且不可重开。返聘或转岗建立新任职，转岗同时结束旧任职。
- 主任职可选，每个用户最多一条。暂停仍可保留主任职，结束清除标记。转岗须明确新任职是否为主任职，
  旧任职上的组织责任按结束规则处理。
- 普通账号停用与普通任职变化各自生效。离职结束全部开放任职及关联的开放责任，禁用账号，提交后撤销原有会话。
  会话撤销失败时离职结果仍生效。删除账号前须处理开放任职和未结束委托。
- Admin 查看当前管理事实和历史。Internal 搜索及第三方资料读取已发布事实，可能晚于源变更。

授权范围见[角色与管理授权](roles-and-authorization.md#admin-权限与-hr-范围)，关联责任见[组织责任管理](#组织责任管理)。
后台操作见[管理后台指南](../guides/admin.md#用户组织岗位与任职)，任职决定见[任职生命周期](../adr/0011-model-employment-as-an-immutable-tenure-lifecycle.md)。

## 组织责任管理

组织责任绑定责任类型、任职和目标组织，是供管理与查询使用的档案事实。业务操作权限由接入应用判断。责任类型由 IAM 维护，管理端只读。

- **管理范围**。完整管理员可全局管理。HR 管理和读取历史时，任职所属组织与目标组织均须在当前范围内，两端可以位于不同的授权树，
  管理员本人也可以是责任人。授权按请求判断，已授权操作可能在撤权后完成。有管理范围的 HR 可读完整类型目录，审计权限单独判断。
- **任命与生命周期**。创建和恢复要求任职及目标组织启用，并满足类型名额。三项绑定创建后固定。暂停保留名额，
  结束保留只读历史且不可恢复。合法重复操作保留操作意图与原有历史时间。
- **任职联动**。暂停任职会暂停其启用的责任。任职恢复后，暂停的责任须显式恢复。任职结束、转岗或离职会结束相关开放责任。
- **查询与历史**。按当前授权范围查询。持有人姓名或账号按不区分大小写的包含条件筛选，与任职、目标组织、类型及状态条件一起在分页前生效。
  历史显示关联对象当前名称和删除状态。软删除后完整管理员仍可能查看历史，HR 可能失去原有范围。关联对象缺失或组织路径损坏会使查询失败。
- **阻塞与拒绝**。范围外的责任也可能占用名额或阻止组织操作。HR 只收到安全提示，可请完整管理员处理。越界与非法状态转换均拒绝。

界面操作见[角色和组织责任](../guides/admin.md#角色和组织责任)，决策见[组织责任模型](../adr/0014-model-organization-responsibility-as-employment-bound-fact.md)。

## 目录搜索

Internal Client 从已发布文档查询用户与组织，覆盖未删除的启用、暂停和禁用对象。精确详情与同发布版本、同披露上下文的完整搜索单项一致。
Admin 查当前管理事实与历史。

- **用户**。可按资料、有效任职、组织、岗位、角色与组织责任组合筛选。同一任职条件由同一条有效任职满足，独立条件可各自匹配。
  匹配、计数、结果和详情按认证 Client 的有效角色及任职上的有效全局角色计算，范围独立于 SSO 配置。字段选择保留有效任职及次序，
  无可见角色的任职返回空角色集合。代办人由[应用委托](client-delegation.md)单独解析。
- **组织**。有效 Internal Client 可查询完整公开组织目录，条件基于组织属性和完整路径。路径保留暂停、禁用祖先，
  层级从根的 1 起算，距离从自身的 0 起算。路径条件可限定同一个节点，两类搜索的组织子树均包含自身。
- **时效**。两类文档均异步发布，源变更后可能读到旧资料。缺失、尚未发布或版本不匹配的文档可缺席。组织独立发布，删除后可能短暂可见，
  祖先编码、名称或类型变化影响后代路径。构建失败时可以继续读取已有合法资料。
- **查询边界**。单次列表与总数来自同一快照，各页各自观察发布状态。完整性校验覆盖本次返回范围，分页总数覆盖整个匹配集合。
  查询非法、超预算、超时或返回范围内文档损坏时，整次查询失败。字段选择不能隐藏损坏。精确详情无可读文档时返回 404，源对象仍可能存在，
  损坏或查询故障返回 503。

调用方式见[搜索接入](../guides/search.md)，完整核验与重建见[数据维护](../releases/data-maintenance.md)。
