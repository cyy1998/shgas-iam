## 通用约定

- 命令从仓库根目录执行；确认目标环境、版本和资源。占位值替换为实际值，配置及秘密通过受控环境提供。
- 按操作的完成标准检查结果。失败或结果未知时停止后续步骤，按该操作的恢复路径处理，不自动扩大范围或重放写入。
- 需要停流时，关闭受影响入口及直连、自动重试和相关任务，确认实际停止并排空在途工作；具体范围由各操作列出。
- 不要求额外保存报告、截图或签认。必要的备份、恢复配置、密钥兼容期计算信息仍须可用；系统日志和业务审计保持原有行为。
- 不把凭据、Token、Cookie、私钥或敏感业务原文写入命令输出、仓库和日志。
