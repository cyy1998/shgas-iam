# 接入指南

面向对接 IAM 的应用开发者，按任务完成配置、调用和失败处理。

| 任务                                    | 指南                             |
| --------------------------------------- | -------------------------------- |
| Custom SSO 业务兑换、托管回调或可信登录 | [Custom SSO 接入](custom-sso.md) |
| 标准 OIDC 登录与退出                    | [OIDC 接入](oidc.md)             |
| 搜索用户或组织                          | [搜索接入](search.md)            |
| 管理委托、解析代办人                    | [委托接入](delegation.md)        |
| 校验、预览和发布网关配置                | [网关接入](gateway.md)           |

功能用途和业务规则见[功能说明](../features/README.md)，部署与恢复见[运维入口](../releases/README.md)。
字段、类型、错误码以各指南链接的 schema、接口定义和测试为准，不另维护一份技术参考。
