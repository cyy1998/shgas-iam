# Env Name Mapping

This change is a breaking env contract rename. It does not migrate real local secret files such as
`apps/*/.env`, `apps/*/.env.local`, `docker/.env`, or production host env files. Only tracked examples,
compose manifests, docs, tests, and app code are updated.

and `NO_PROXY` are not part of the app raw env contract.
